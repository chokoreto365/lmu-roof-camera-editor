# 使用说明

## 一、这是什么

LMU 可视化车顶相机编辑器，用来修改 Le Mans Ultimate 的相机配置文件 `UserData\Cameras\<车辆名>.CAM`。

它解决三件事：

1. 不用手动改文件名、找目录，一键给所有车装车顶视角。
2. 每辆车可以单独调相机位置，侧视／俯视拖动更直观。
3. 720S 这类“参数生效但看不到车身”的车，可以切到能看到车身的视角槽位。

它**不能**做到游戏画面内实时变化：`.CAM` 不会可靠热重载，改完必须重进赛道会话。

## 二、第一次使用

1. 完全退出 LMU。
2. 双击 `LMU可视化车顶相机编辑器.exe`。
3. 工具一般会自动找到 Steam 里的游戏目录；没找到就点“浏览…”选 `...\steamapps\common\Le Mans Ultimate`。
4. 点“扫描”，左侧出现车辆列表。
5. 选一辆车，拖动右侧橙色相机点，或在下方数值框输入。
6. 点“保存当前车 CAM”。也可以直接点“写入全部车辆”。
7. 首次保存会顺带把 `Settings.JSON` 里的 `Broadcast Custom Cameras` 打开（会自动备份）。
8. 启动游戏 → 进入赛道 → 切到 **TVCOCKPIT（电视座舱）**。

## 三、界面怎么用

- **左侧车辆列表**：显示识别到的车。状态列“已有”表示目录里已经有 CAM；“未保存”表示你改过但还没写盘。
- **侧视图**：横向是前后 Z，纵向是上下 Y。拖动橙色点即可。
- **俯视图**：横向是左右 X，纵向是前后 Z。
- **精确参数**：单位是厘米和角度，写进文件时自动换算成米和弧度。
- **视角槽位**：
  - `TVCOCKPIT（电视座舱）`：常规车顶视角。
  - `ONBOARD000（随车外部试验）`：随车外部视角，车模显示更完整，适合 720S 这类看不到车身的情况。
- **同时更新 NOSE**：附加写入 NOSE 槽位。部分车在 NOSE 下完全不画车身，不建议 720S 使用。
- **当前车建议值**：恢复该车的推荐起点（720S 会顺便切到 ONBOARD000）。
- **重新读取当前 CAM**：丢弃未保存的修改，从磁盘重读。
- **恢复首次修改前的原始文件**：按备份清单还原，需要关闭游戏。

## 四、参数方向（重要）

| 参数 | 方向 | 说明 |
| --- | --- | --- |
| X | 正值向右 | 用于左右挪一点，一般保持 0 |
| Y | 正值向上 | 视线抬高；太高会变成“悬空” |
| Z | **正值向后，负值向前** | 720S 实测结论；要看到更多车身就加大 Z |
| 俯仰 | 负值向下 | 单位是度，文件里是弧度 |

> 相机坐标系由游戏和车模共同决定，少数车辆可能出现方向差异。以实际画面为准，把实测结果记下来即可。

## 五、推荐起点

大多数车：

```
视角槽位：TVCOCKPIT
X=0, Y=90 cm, Z=65 cm, 俯仰=-8°
```

720S（要看见车身）：

```
视角槽位：ONBOARD000
X=0, Y=55 cm, Z=15 cm, 俯仰=-11.5°，近裁剪 0.01 m
```

如果车身出现了但还想更靠后：Z 每次加 5～25 cm，保存后重进会话看效果。Z 的界面范围是 −500～+500 cm，这只是工具限制，不是引擎上限。

## 六、游戏运行中微调

首次启用完成后，可以边玩边调：

1. 保持游戏运行，Alt+Tab 切到编辑器。
2. 选中车辆，改参数，点“保存当前车 CAM”。
3. 回游戏，**中止当前会话并重新开始**，或退回主菜单重新进入比赛。

明确区分：

- 回 P 房、进站、切换视角、暂停：**不会**重新加载 CAM。
- 重新开始／重进赛道会话：**会**重新加载。
- 完全退出游戏：通常不需要。

如果某次没生效，再完全重启游戏确认一次。

## 七、720S 看不到车身

现象：调参数时画面确实会动，但始终没有车头／车顶。

原因：不是坐标不对，而是该视角槽位没有绘制车模（或车模被裁掉）。

处理：

1. 选中 720S，点“当前车建议值”，槽位变成 `ONBOARD000`。
2. 保存，重新加载会话。
3. 游戏内切到 **ONBOARD000／车载 1**，不要用 TVCOCKPIT 或 NOSE。
4. 车身出现后再用 Z 往后退，直到构图满意。

如果 ONBOARD000 也没有车身，建议先切游戏自带的几个车载视角确认车模本身正常，再回到工具里调。

## 八、备份与恢复

备份位置：`%LOCALAPPDATA%\LMUCamStudio\Backups`

- 只记录工具实际改过或新建的文件。
- 原始存在的文件：恢复成第一次修改前的内容。
- 工具新建的文件：恢复时删除。
- 未纳入清单的文件：不动。

需要还原时，关闭游戏，点“恢复首次修改前的原始文件”。

## 九、常见问题

**Q：游戏里怎么切车顶视角？**
相机槽位生效后，在驾驶视角循环里切到 TVCOCKPIT（电视座舱）或 ONBOARD000（车载 1），具体名称取决于你装的本地化语言。

**Q：为什么不能像调座椅那样在游戏里实时拖？**
游戏内座椅键只对车内 COCKPIT 生效，对 TVCOCKPIT／NOSE／ONBOARD 无效；而且 `.CAM` 不支持可靠热重载。

**Q：能不能读游戏进程内存做实时版？**
不建议。LMU 开启 EAC 时会直接拒绝外部进程读取（Windows 错误 5），绕过保护属于明确禁止的行为，本工具不做。

**Q：新增的车没出现在列表里？**
先用车跑一次，让游戏写入车辆记录和日志，再点“扫描”。

**Q：会影响联机吗？**
只在单机使用。不要带着任何非官方修改进联机比赛。

## 十、从源码构建

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

只需 Windows 自带 .NET Framework 4.x 编译器，不需要 Visual Studio。
